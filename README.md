# Cortex AI

A lightweight, responsive landing page for an AI automation service serving businesses across India.

## Run locally

```sh
pnpm install
pnpm dev
```

Open the local URL printed by Vite. To create a production build, run `pnpm build`; the output is written to `dist/`.

## Lead form

The form currently shows a success message in the browser. Connect it to a form service or backend before using it to collect real enquiries.
